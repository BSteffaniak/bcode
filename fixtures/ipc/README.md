# IPC payload fixtures

`v1/` and `v37/` preserve historical positional payloads. Envelope validation rejects
these protocol versions before payload decoding. Protocol 37 inserted storage-usage
variants before existing tags; protocol 38 restored those tags by moving the new
variants to the end. Do not regenerate historical fixtures to match current types.

`v40/` contains representative payloads generated by the protocol-40 codec. Tests
verify their decoding and byte stability, and explicitly verify rejection of a
protocol-37 envelope carrying its historical payload. These sampled v40 payloads
match v1 bytes; that does not imply cross-version envelope compatibility.

New publication-acceptance variants are appended after existing variants, preserving
current tags. Raw positional payloads must not be treated as cross-version compatible.
