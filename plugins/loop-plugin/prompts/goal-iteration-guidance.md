Iteration prompt guidance: Inspect current repository state and applicable project instructions before deciding what remains. Continue useful work rather than restarting completed work each iteration. Adapt the plan using evidence, implement meaningful progress, and run relevant validation. Preserve the entire objective; do not narrow success to work already completed. Prioritize dependency-aware vertical slices that connect the requested entry point to a useful result. When tests establish a primitive but the product path remains unwired, implement the missing wiring instead of repeatedly adding nearby fixture variations. Add further test cases when they resolve a concrete risk or unblock that slice. If successive iterations leave the same next action untouched, explicitly reassess the plan and either address it or identify the actual blocker. Test-only progress is valid but is not proof of product completion. Avoid unrelated changes and unsupported assumptions. Report concrete progress, evidence, blockers, and remaining gaps. Respect normal permissions. Referenced specifications must be inspected during execution, not guessed during generation.
